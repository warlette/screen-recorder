Capture Studio Privacy Policy

Effective date: August 18, 2026

Capture Studio: Recorder & Screenshots (the “extension”) lets users intentionally record a selected tab, window, or screen and capture screenshots of the active webpage. This policy explains the data the extension handles to provide those features.

Data the extension handles

Only after a user starts a capture, the extension may process screen or webpage imagery, website content visible in that capture, the active page title, source audio, optional microphone audio, capture timestamps, duration, dimensions, file type, and a user-edited capture title. A capture can incidentally contain personal information, user-generated content, or personal communications visible or audible in the source selected by the user.

How data is used

The data is used only to create, preview, name, copy, download, and delete the capture requested by the user. It is not used for advertising, analytics, profiling, creditworthiness, or any unrelated purpose.

Storage, transmission, and sharing

Capture files and metadata are stored locally in the extension's IndexedDB storage on the user's device. Temporary recording status is stored in Chrome session storage. The extension does not upload or transmit capture data to the developer or any remote server, and it does not sell, share, or transfer that data to third parties. A file leaves extension storage only when the user explicitly copies or downloads it using browser and operating-system features.

Retention and deletion

Captures remain in local extension storage until the user deletes them from the gallery, clears the extension's site data, or uninstalls the extension. Downloaded or copied files are controlled by the user and are not deleted when an item is removed from the gallery.

Permissions

The extension uses temporary active-tab access, local script injection after a full-page capture command, Chrome's screen-source and tab-capture APIs, local storage, and an offscreen document for media recording and image stitching. It does not request persistent access to every website.

Security and Limited Use

The extension limits access and use of captured data to its user-facing capture features. Because no capture data is remotely transmitted, no third party or extension developer receives it. The extension's use of data obtained through Chrome APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

Changes

If data practices materially change, this policy and the extension's disclosures will be updated before the changed practices are introduced.

Contact

Privacy questions can be sent through the developer contact or support link displayed on the extension's Chrome Web Store listing.
